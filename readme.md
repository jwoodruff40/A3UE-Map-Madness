Extender for Antistasi Ultimate allowing you to change which zones (outposts / milbases / airports / resources / factories) invaders and occupants control at the start of the game.

Only works for new games.

Minor bugs present and known:
- error about CfgMarkerColors when closing the dialog, doesn't harm anything
- zome zones lose their names in the UI when you switch their side

How to use:

- Check new game in the setup UI
- Click Map Madness button
- Click a zone to switch its side. Click it again to switch it back.
- Use the checkboxes on the left side of the map to show / hide zone types for easier editing
- Click close button in the top left or use ESC key to exit the editor - then just finish setting up your game (factions / params) and start the game.

Important notes:
- This is NOT CURRENTLY COMPATIBLE WITH FACTION MADNESS (as both mods overwrite parts of the AU setup UI - compat is planned later)
